# React Boilerplate

Opinionated React + TypeScript + Vite boilerplate.

Setup

1. Install dependencies:

```bash
npm install
```

2. Start dev server:

```bash
npm run dev
```

Scripts

- `npm run dev` — run dev server
- `npm run build` — build production
- `npm run test` — run tests
- `npm run lint` — run ESLint
- `npm run typecheck` — run type check

Environments

This repo includes multiple `.env` files prefixed with `VITE_`.
